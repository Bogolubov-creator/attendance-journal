# FirstVDS

Приложение рассчитано на VDS/VPS с Linux и постоянным диском.

Если сервер новый и пустой – использовать Docker Compose и Caddy по [DEPLOY.md](DEPLOY.md). Если на сервере уже есть сайты или панель управления – сохранить существующий веб-сервер, подключить приложение на отдельном домене через него. Не запускать второй прокси на занятых 80/443.

Рабочий режим: AUTH_MODE=selection, DEMO_MODE=false, APP_ORIGIN с HTTPS. Вход по роли и имени; университетские ключи не требуются. Это не подтверждение личности, доступ посетителей нужно ограничивать отдельно, если сайт содержит персональные данные.

Сервер ещё не подключался. Неизвестны ОС, панель, домен и занятость портов; поэтому команды установки системных пакетов и изменения действующей конфигурации здесь не выполнялись.
