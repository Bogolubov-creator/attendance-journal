# Замер скорости журнала

Не входит в `npm test`, запускается вручную.

## 1. Копия базы

Замер работает только с копией, рабочую базу владельца не трогает:

```
sqlite3 <база>.sqlite ".backup <копия>.sqlite"
```

## 2. Генератор базы «год»

Наполняет копию отметками за учебный год (150 учебных дней, связка
«преподаватель – дисциплина – студент» раз в неделю при factor=1):

```
node scripts/bench/gen-year.mjs <копия>.sqlite [factor=1]
```

## 3. Замер

```
node scripts/bench/bench.mjs <копия>.sqlite [N=20]
```

- `N` – число повторов каждого запроса (по умолчанию 20).
- Сервер поднимается на порту `3131` (переменная `BENCH_PORT`), после замера
  сам останавливается.
- Результаты (JSON и загрузки сервера на время замера) пишутся во временную
  папку ОС, а не в репозиторий: по умолчанию `<tmp>/attendance-bench`,
  переменная `BENCH_OUT_DIR` меняет путь.

Скрипт печатает в консоль медианы и p95 времени ответа основных маршрутов
(обзор реестра, карточка студента, список преподавателей, сохранение
отметок, посещаемость и требования студента), вес обзора и статики, а также
время `/healthz` и сохранения отметок преподавателем при пяти параллельных
обзорах. Полный JSON того же прогона
сохраняется в `BENCH_OUT_DIR`.
