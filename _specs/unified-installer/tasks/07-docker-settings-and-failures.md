## Что построить

Ревью 25.09, ось «Спека»:
- В compose.yaml у сервиса журнала `environment` жёстко задаёт `BACKUP_KEEP: "14"` и `TRUST_PROXY: "1"`, а `environment` важнее `env_file` – ответы установщика «Сколько копий» и «Сколько прокси» при установке через Docker молча не действуют (К6, К9). Нужно, чтобы значения из `.env` применялись, а без них оставались прежние умолчания.
- При встроенном Caddy `docker compose up -d --build` сам падает, если журнал не стал здоровым (Caddy ждёт `service_healthy`), и установщик останавливается без последних строк журнала (К11). Нужно при любом неуспехе запуска показывать последние строки журнала.
- Проверка здоровья Compose (`interval: 30s`) первый раз срабатывает около 30-й секунды; ожидание 60 секунд на удалённом сервере даёт ложный провал при медленном старте. Нужен запас ожидания или более частая проверка.

## Критерии приёмки

- [x] При установке через Docker `BACKUP_KEEP` и `TRUST_PROXY` из `.env` доходят до журнала; без них – прежние 14 и 1 (К6, К9).
- [x] Неуспешный `docker compose up` (локально и на сервере) показывает последние строки журнала, ничего не удаляет, выход с ошибкой (К11).
- [x] Ожидание здоровья на сервере не проваливается раньше, чем Compose успевает проверить журнал хотя бы дважды.
