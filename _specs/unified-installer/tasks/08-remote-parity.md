## Что построить

Ревью 25.09, ось «Спека»:
- Спека: «Ключи запуска: выбор сценария без вопросов (этот компьютер через Docker, без Docker, удалённый сервер)» – ключа для удалённого сервера нет.
- К5: «Перезаполнить настройки можно только отдельным ключом запуска с подтверждением» – для сервера `--reconfigure` игнорируется.
- К14 («безопасная остановка»): удалённое обновление сначала останавливает журнал, потом копирует код; если `scp` не прошёл, журнал на сервере остаётся остановленным. Код должен уезжать на сервер до остановки журнала.

## Критерии приёмки

- [ ] Ключ `--remote` пропускает вопрос «куда ставить» и ведёт в удалённый сценарий.
- [ ] `--reconfigure` на сервере с прежней установкой: подтверждение, копия прежнего `.env` на сервере, новые настройки; база и сканы не тронуты (К5).
- [ ] Удалённое обновление: код загружается до остановки журнала; сбой загрузки оставляет журнал работающим (К14).
