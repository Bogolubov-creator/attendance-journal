# 05: На живых данных нет списка студентов и демо-входа студентом

**Статус:** todo

**Блокируется:** ничем (можно брать сразу).

**Закрывает критерии:** К4.

## Что построить

Если журнал запущен в демо-режиме, но на живых данных (`DATA_MODE=live`), анонимный запрос состояния сессии больше не отдаёт список ФИО студентов, на экране входа нет пункта «Студент (демо-вход)», а сервер отклоняет демо-вход с ролью студента. На тестовой базе (демо-режим без живых данных) демо-вход студентом работает как раньше.

## Критерии приёмки

- [ ] Сначала падающий тест: демо-режим + `DATA_MODE=live`, анонимный запрос состояния сессии – список студентов пуст.
- [ ] Там же демо-вход с ролью студента отклоняется (403 или 404), кабинет не открывается.
- [ ] Демо-режим на тестовой базе: список студентов есть, демо-вход студентом открывает кабинет (существующие тесты кабинета проходят без изменения ожиданий).
- [ ] Экран входа сам скрывает пункт «Студент (демо-вход)», когда список пуст (проверить, что это уже так, и не менять разметку без нужды).
- [ ] Все тесты зелёные, prettier чист.
