# 01: Замер скорости живёт в репозитории

**Статус:** done

**Блокируется:** ничем (можно брать сразу).

**Закрывает критерии:** нет (подготовка к К13–К15).

## Что построить

Разработчик одной командой генерирует базу «год» (187 студентов × 150 учебных дней, связка «преподаватель – дисциплина – студент» раз в неделю) из копии любой базы и получает таблицу медиан времени ответа основных маршрутов, размер ответа обзора и время `/healthz` под пятью одновременными обзорами. Сейчас эти скрипты лежат в скретчпаде сессии аудита и пропадут вместе с ней.

## Критерии приёмки

- [x] Генератор базы «год» и скрипт замера лежат в репозитории, рядом короткий README: как запустить, какой порт, что печатает.
- [x] Скрипт замера сам поднимает сервер на своём порту (не 3100, 3112, 3120), сам гасит его и пишет итог в JSON вне репозитория.
- [x] Число повторов задаётся параметром; рабочая база владельца не читается и не пишется – только переданная копия.
- [x] Прогон на базе «год» воспроизводит порядок чисел «до» из спеки (обзор ≈14 с, ≈11,9 МБ) – числа записаны в сообщении коммита.
- [x] `npm test` не запускает скрипты замера; все тесты зелёные, prettier чист.
