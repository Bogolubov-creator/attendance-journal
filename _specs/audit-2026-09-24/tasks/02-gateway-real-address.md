# 02: Шлюз считает попытки по реальному адресу соединения

**Статус:** todo

**Блокируется:** ничем (можно брать сразу).

**Закрывает критерии:** К1.

## Что построить

Временный шлюз доступа (Basic-пароль перед журналом) перестаёт доверять заголовку X-Forwarded-For при подсчёте неверных паролей: ключ счётчика – адрес сокета. Перебор пароля с подменой заголовка упирается в 429 так же, как без неё. Формат конфигурации шлюза и его поведение для правильного пароля не меняются.

## Критерии приёмки

- [ ] Сначала падающий тест: шлюз и заглушка приложения на свободных портах, 11 запросов с неверным паролем и разным X-Forwarded-For – 11-й получает 429.
- [ ] Порт шлюза и адрес приложения можно задать переменными окружения; по умолчанию прежние значения (3112 и 127.0.0.1:3100), живой запуск владельца без изменений.
- [ ] Правильный пароль по-прежнему проксирует запрос и снимает счётчик.
- [ ] Хеш пароля и формат файла конфигурации не меняются.
- [ ] Все тесты зелёные, prettier чист.
