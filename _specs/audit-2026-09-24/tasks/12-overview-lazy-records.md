# 12: Обзор без списка занятий, подгрузка при раскрытии

**Статус:** todo

**Блокируется:** 11 (подгрузка опирается на быструю карточку одного студента).

**Закрывает критерии:** К14, К15.

## Что построить

Обзор реестра отдаёт у каждого студента число занятий вместо их полного списка. В таблице реестра по-прежнему «Занятия: N»; по клику список занятий подгружается с сервера для одного студента и раскрывается с тем же содержимым, что раньше. Пока идёт загрузка – короткое состояние «Загрузка…», при ошибке – понятный текст. Благодаря задаче 11 и этой одновременные обзоры больше не душат сохранение отметок.

## Критерии приёмки

- [ ] Сначала падающий тест: в ответе обзора нет списка занятий, есть число занятий, совпадающее с прежней длиной списка.
- [ ] Маршрут одного студента по-прежнему отдаёт список занятий в прежнем виде.
- [ ] Тест интерфейса на jsdom: клик по «Занятия: N» запрашивает занятия этого студента и показывает их; повторный клик сворачивает без нового запроса.
- [ ] Выгрузка CSV реестра не потеряла ни одного столбца.
- [ ] Замер на базе «год»: ответ обзора < 300 КБ; при пяти одновременных обзорах `/healthz` и сохранение отметок преподавателем < 3 с. Числа – в сообщении коммита.
- [ ] Проверка в браузере на своём порту: реестр, раскрытие занятий у двух студентов, карточка – как раньше.
- [ ] Все тесты зелёные, prettier чист.
