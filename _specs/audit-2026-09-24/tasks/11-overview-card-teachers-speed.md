# 11: Обзор, карточка и список преподавателей без квадратичного роста

**Статус:** done

**Блокируется:** 01 (нужен замер в репозитории).

**Закрывает критерии:** К13 (обзор реестра, карточка студента, список преподавателей).

## Что построить

Расчёт строк реестра перестаёт фильтровать весь массив отметок и связок внутри цикла по студентам: отметки раскладываются по студенту один раз на запрос, связки «преподаватель – дисциплина – студент» – по студенту и по преподавателю один раз при загрузке и после импорта. Карточка студента считается только для запрошенного студента. Форматтер московской даты и сортировщик строк по-русски создаются один раз на модуль. Содержимое ответов не меняется.

## Критерии приёмки

- [x] Сначала тест, фиксирующий содержимое ответов обзора, карточки и списка преподавателей на тестовой базе с отметками (если такого теста нет) – проходит до и после правки без изменения ожиданий.
- [x] После импорта реестра словари связок пересобираются (тест: импорт меняет связки – обзор и список преподавателей это отражают).
- [x] Замер на базе «год»: медиана обзора < 2 с, карточки < 200 мс, списка преподавателей < 100 мс. Числа до и после – в сообщении коммита.
- [x] Все тесты зелёные, prettier чист.
