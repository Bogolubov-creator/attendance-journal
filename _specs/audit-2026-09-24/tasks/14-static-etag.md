## Что построить

Файлы интерфейса (скрипты, стили, картинки, страницы) отдаются с `Cache-Control: no-cache` и ETag: браузер переспрашивает сервер и при неизменном файле получает 304 без тела. Ответы API и страницы со сканами по-прежнему `no-store`. Остальные заголовки безопасности не меняются.

- [x] Сначала падающий тест: запрос скрипта интерфейса отдаёт ETag и `no-cache`; повторный запрос с `If-None-Match` получает 304.
- [x] Тест: ответ API и отдача скана – `no-store`.
- [x] CSP, nosniff, запрет встраивания и прочие заголовки безопасности на статике те же, что до правки (сравнить в тесте).
- [x] Все тесты зелёные, prettier чист.
