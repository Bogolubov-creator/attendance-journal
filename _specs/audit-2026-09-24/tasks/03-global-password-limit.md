# 03: Общий счётчик неверных паролей

**Статус:** todo

**Блокируется:** ничем (можно брать сразу).

**Закрывает критерии:** К2.

## Что построить

Вход по общему паролю (режим выбора сотрудника, демо-вход) ограничен не только по адресу (5 неверных за 15 минут), но и суммарно: 30 неверных попыток с любых адресов за 15 минут закрывают вход по паролю на остаток окна для всех. Смена адреса больше не даёт бесконечного перебора.

## Критерии приёмки

- [ ] Сначала падающий тест: при доверии прокси 30 неверных попыток с разными X-Forwarded-For, 31-я с нового адреса получает 429 (сейчас 403).
- [ ] Существующее ограничение по адресу (5 за 15 минут) работает как раньше.
- [ ] Удачный вход обнуляет счётчик своего адреса, общий счётчик не обнуляет.
- [ ] Текст ошибки 429 – прежний русский.
- [ ] Все тесты зелёные, prettier чист.
