# 06: Предел распаковки при импорте Excel

**Статус:** done

**Блокируется:** ничем (можно брать сразу).

**Закрывает критерии:** К5.

## Что построить

Загрузка реестра Excel, чьё содержимое после распаковки больше 50 МБ (zip-бомба), отклоняется с 400 и понятным русским текстом, журнал продолжает работать. Распаковываются только записи архива, нужные для чтения листов. Обычный реестр грузится как раньше.

## Критерии приёмки

- [x] Сначала падающий тест: сгенерированный в тесте xlsx с записью, распаковывающейся больше чем в 50 МБ, – ответ 400, затем `/healthz` отвечает 200.
- [x] Предел действует и на одну запись, и суммарно на все распакованные записи.
- [x] Записи архива, не нужные для чтения листов (картинки, темы, стили и т. п.), не распаковываются.
- [x] Существующие тесты импорта реестра проходят без изменения ожиданий.
- [x] Все тесты зелёные, prettier чист.
