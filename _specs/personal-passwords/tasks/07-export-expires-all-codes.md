# 07: Новая выгрузка гасит все прежние неиспользованные коды

**Статус:** done

**Блокируется:** ничем (можно брать сразу)

**Закрывает критерии:** К11

## Что построить

Ревью 24.09: «неиспользованные коды из прежних выгрузок и выдач перестают действовать» выполнено не полностью. Массовая выгрузка выдаёт новые коды только тем, кто в неё попал, а коды, выданные поштучно преподавателю без студентов или тому, кто с прошлой выгрузки потерял студентов, продолжают действовать. Потерянный старый файл или письмо остаются опасными. Нужно, чтобы выгрузка гасила неиспользованные коды у всех учётных записей без пароля, а новые коды получали только попавшие в файл.

## Критерии приёмки

- [x] Код, выданный поштучно преподавателю без студентов, после массовой выгрузки не принимается (К11).
- [x] Коды попавших в файл действуют, пароли и сессии сотрудников с паролем не тронуты (К11).
