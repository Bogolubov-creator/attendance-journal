# 04: Массовая выгрузка кодов приглашения

**Статус:** todo

**Блокируется:** 03

**Закрывает критерии:** К11, К17 (выгрузка), К20 (код в выгрузке)

## Что построить

У полного доступа на странице «Сотрудники» – кнопка «Выгрузить коды приглашения». Перед выгрузкой журнал предупреждает: файл содержит действующие коды, его нужно удалить после рассылки. Выгрузка – CSV для Excel (с BOM и защитой от формул, как существующие выгрузки, без кэширования): ФИО, роль, логин, код, действует до. В файл попадают преподаватели, у которых есть студенты, и сотрудники учебного офиса – только те, у кого ещё нет пароля. Каждому из них выдаётся новый код; неиспользованные коды из прежних выгрузок и поштучных выдач гаснут. У сотрудников с паролем ничего не меняется. Тем, у кого ещё нет логина, он создаётся по общим правилам.

## Критерии приёмки

- [ ] Выгрузка доступна только полному доступу; менеджер и преподаватель получают 403 (К11).
- [ ] CSV содержит столбцы ФИО, роль, логин, код, действует до; открывается в Excel с правильной кодировкой; ячейки защищены от формул (К11).
- [ ] В файле ровно преподаватели со студентами и сотрудники офиса без пароля; преподавателей без студентов и сотрудников с паролем в нём нет (К11).
- [ ] У сотрудников с паролем после выгрузки пароль и сессии работают как прежде (К11).
- [ ] Коды из предыдущей выгрузки и поштучной выдачи после новой выгрузки не принимаются, новые – принимаются (К11).
- [ ] Выгрузка пишется в журнал изменений с числом выданных кодов, без самих кодов (К17, К20).
- [ ] Предупреждение перед выгрузкой проверено в jsdom.
