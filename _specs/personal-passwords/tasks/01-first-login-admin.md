# 01: Первый вход администратора по коду с сервера

**Статус:** done

**Блокируется:** ничем (можно брать сразу)

**Закрывает критерии:** К1, К2, К3, К12, К17 (первый вход), К20

## Что построить

Владелец сервера запускает серверный скрипт с ID сотрудника полного доступа из справочника учебного офиса. Скрипт заводит этому сотруднику учётную запись с логином вида «фамилия.ио» и печатает логин и код приглашения (действует 7 дней). На экране входа появляется ссылка «Первый вход»: форма с логином, кодом, новым паролем и повтором. Пароль короче 10 символов или из списка распространённых отклоняется с объяснением. При верном коде пароль задаётся, код гаснет, человек попадает в свой кабинет. Сессия выдаётся с новым источником входа «личный пароль» и помнит номер версии пароля: прослойка сессии закрывает её, если версия сменилась или учётная запись исчезла.

Здесь же закладывается основа для остальных тасок: таблица учётных записей сотрудников, генерация уникального логина (транслитерация, отбрасывание «Вак_», цифра при совпадении), генерация и хеширование кода, проверка пароля по длине и списку распространённых. Роль вычисляется по тому, где найден человек, – в справочнике офиса или в реестре преподавателей.

Старый вход (выбор из списка и общий пароль) не меняется.

## Критерии приёмки

- [x] Серверный скрипт для указанного сотрудника полного доступа печатает логин и код; по ним через «Первый вход» задаётся пароль и открывается кабинет полного доступа (К1).
- [x] Скрипт отказывает, если ID не найден в справочнике или сотрудник не полного доступа.
- [x] Первый вход с действующим кодом и допустимым паролем открывает кабинет своей роли; повторно тот же код не принимается (К2).
- [x] Неверный, истёкший (срок подменён в тестовой базе) или использованный код отклоняется сообщением «Код не подходит или истёк – попросите новый у менеджера своей программы», пароль не задаётся (К2).
- [x] Пароль короче 10 символов и пароль из списка распространённых (без учёта регистра) отклоняются с объяснением; несовпадение с повтором ловится в форме (К3).
- [x] Логин – «фамилия.ио» латиницей в нижнем регистре, без «Вак_»; для однофамильца с теми же инициалами выдаётся логин с цифрой 2, 3… (К12).
- [x] В базе нет пароля и кода в открытом виде – только хеши; код появляется только в выводе скрипта (К20).
- [x] Первый вход пишется в журнал изменений с именем сотрудника; ни пароль, ни код в запись не попадают (К17, К20).
- [x] Сессия по личному паролю закрывается при следующем запросе, если в базе сменилась версия пароля или удалена учётная запись.
- [x] Прежние тесты входа по общему паролю и кабинета студента проходят без изменений.
