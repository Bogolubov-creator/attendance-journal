# 05: Смена своего пароля

**Статус:** todo

**Блокируется:** 02

**Закрывает критерии:** К3 (при смене пароля), К14, К17 (смена пароля)

## Что построить

В меню под именем сотрудника, вошедшего по личному паролю, – пункт «Сменить пароль». Форма: текущий пароль, новый, повтор. Без верного текущего пароля смена не проходит. Новый пароль проверяется по тем же правилам, что при первом входе. После смены прочие сессии этого сотрудника закрываются, а текущее устройство остаётся в журнале. Сотруднику, вошедшему по общему паролю, пункт не показывается.

## Критерии приёмки

- [ ] Смена с неверным текущим паролем отклоняется, пароль не меняется (К14).
- [ ] Новый пароль короче 10 символов или из списка распространённых отклоняется (К3).
- [ ] После смены старый пароль не принимается, новый – принимается; другая сессия того же сотрудника закрыта, текущая продолжает работать (К14).
- [ ] Неверный текущий пароль учитывается в счётчике блокировки учётной записи.
- [ ] Смена пишется в журнал изменений без паролей (К17).
- [ ] Пункт меню и форма проверены в jsdom; при входе по общему паролю пункта нет.
